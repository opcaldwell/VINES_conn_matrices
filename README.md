# FERN_postprep 

### FERN Lab @ UVM

An adapted script from the Stanford STAI Lab to post-process fMRIPrep outputs.
Before running, update #### for sub id's in config/sbatch files. Sbatch can be submitted from there. 

See original documentation here: https://stai.stanford.edu/fmri/, or at zendodo page https://zenodo.org/records/17516604.
